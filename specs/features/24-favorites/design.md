# Design: Favoritos

**ID:** F24 &nbsp;|&nbsp; **Slug:** `24-favorites`

## Contexto

Este documento describe el diseno tecnico para cumplir `requirements.md` de esta misma feature.
Antes de implementar, revisar `_global/02-architecture-and-structure.md` y `_global/03-conventions.md`.

## Decisiones de diseno

- Tabla simple `FavoriteRoutine { routineId }` en base de datos local, independiente de si la rutina es preset o custom (referencia generica por id).
- Widget reutilizable `FavoriteToggleButton` usado en todas las listas/detalles de rutina.
