# Design: Modo Oscuro

**ID:** F27 &nbsp;|&nbsp; **Slug:** `27-dark-mode`

## Contexto

Este documento describe el diseno tecnico para cumplir `requirements.md` de esta misma feature.
Antes de implementar, revisar `_global/02-architecture-and-structure.md` y `_global/03-conventions.md`.

## Decisiones de diseno

- Definir `ThemeData` claro y oscuro centralizados en design-system.md, usando `ColorScheme` de Material 3.
- Prohibir colores hardcodeados en widgets; todo color debe venir de `Theme.of(context)`.
- Los colores personalizados de intervalos (F01) deben tener suficiente contraste calculado dinamicamente sobre fondo claro/oscuro (no asumir un solo fondo).
