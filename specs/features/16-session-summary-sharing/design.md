# Design: Compartir Resumen de Sesion

**ID:** F16 &nbsp;|&nbsp; **Slug:** `16-session-summary-sharing`

## Contexto

Este documento describe el diseno tecnico para cumplir `requirements.md` de esta misma feature.
Antes de implementar, revisar `_global/02-architecture-and-structure.md` y `_global/03-conventions.md`.

## Decisiones de diseno

- Renderizado de la tarjeta resumen via `RepaintBoundary` + captura a imagen (`dart:ui`), evita depender de servicios externos de generacion de imagenes.
- Paquete `share_plus` para invocar el share sheet nativo.
- Plantilla visual de la tarjeta definida en design-system.md (colores, tipografia, logo de marca de agua).
