# Design: Multilenguaje (i18n)

**ID:** F28 &nbsp;|&nbsp; **Slug:** `28-multi-language-i18n`

## Contexto

Este documento describe el diseno tecnico para cumplir `requirements.md` de esta misma feature.
Antes de implementar, revisar `_global/02-architecture-and-structure.md` y `_global/03-conventions.md`.

## Decisiones de diseno

- Uso de `flutter_localizations` + `intl` con archivos `.arb` por idioma.
- El locale seleccionado se propaga tanto a los `Intl` de UI como al `TtsProvider` (F02/F07) para que la voz hable en el idioma correcto.
- Contenido de rutinas (F03) estructurado con claves de traduccion separadas del JSON de estructura (intervalos/duraciones no cambian por idioma).
